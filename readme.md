# Portfolio Overview

This repository contains my weekly p5.js studies and a final pixel-based project. Each week explores a specific idea with a small, focused sketch. Below are short summaries and where to find the live embeds.

## Day 01 — Simple House
- First p5.js exercise using only basic shapes (rect, triangle, circle).
- Goal: learn coordinates, layering, and color.
- Files: `day01.md`, assets in `content/day01/`

## Day 02 — Grids and Patterns
- Experiments with repeating forms (hex grid, arcs, color rhythm).
- Focus on spacing, symmetry, and playful interaction.
- Files: `day02.md`, embeds: `content/day01/01/` and `content/day01/02/`

## Day 03 — Clock / Time
- An abstract, evolving “clock” that maps time to motion, color, and rotation.
- Highlights cyclic change rather than digits.
- Files: `day03.md`, embed: `content/day01/03/`

## Day 04 — Drawing Machines
- Rule‑driven systems that “draw themselves” (harmonograph and portal‑like energies).
- Idea: small parameter changes → very different linework.
- Files: `day04.md`, embeds: `content/day01/0401/`, `content/day01/04.02/`, `content/day01/0403/`

## Day 05 — Faces / Parametric Generators
- A face template with randomized parameters (eyes, brows, mouth, hair).
- 4×3 grid, button to regenerate; mood value ties features together.
- Files: `day05.md`, embed: `content/day01/05/`

## Day 06 — Pixels as Material
- Work directly with image pixels to recompose visuals (grid dots, polar remap).
- Uses `sunset.png` as source; RGB sampling for faithful colors.
- Files: `day06.md`, embed: `content/day01/06/`

## Final Project — Pixel Sunset (3 Iterations)
- Iteration I (`Project01`): flat color bands, sun, and blocky waves to test layout.
- Iteration II (`Project02`): animated pixel grid with gradients, waves, and clouds.
- Iteration III (`Project03`): “story” layer—dolphins, breathing shoreline, and a couple on the beach. Responsive canvas and cell size.
- Files: `Project.md`, embeds: `content/day01/Project01/`, `Project02/`, `Project03/`

Tip: open each `.md` file for screenshots, short write‑ups, and the live iframes that load the corresponding `embed.html` and `sketch.js`.
